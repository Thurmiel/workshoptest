# Home Assistant Add-ons

A collection of custom add-ons for Home Assistant.

**Add-on Documentation**: <https://developers.home-assistant.io/docs/add-ons>

## Installation

Add this repository to your Home Assistant instance:

1. Go to **Settings > Add-ons & Automations > Add-ons > Repositories**
2. Add the repository URL: `https://github.com/<YOUR_USERNAME>/<YOUR_REPO>`
3. Browse and install any add-on from this repository
